Speed Paths

Gain a configurable Speed effect while walking on Dirt Paths, making roads faster and more rewarding to build.

Type Datapack / Mod
Version 1.21.9 - 26.2
Status Released

About

Speed Paths is a datapack that grants players a configurable Speed effect whenever they walk on Dirt Path blocks, making roads a valuable part of survival gameplay.

Whether you're connecting villages, your base or important locations, Speed Paths rewards players for building proper road networks by making travel significantly faster.

Everything is fully configurable through built-in commands, allowing you to choose the Speed level that best fits your world without editing any files.

Features

Speed Boost

Automatically gain a Speed effect while walking on Dirt Path blocks.

Fully Configurable

Choose any Speed level from I to V directly in-game.

Vanilla Friendly

Encourages road building without changing Minecraft's natural progression.

Commands

Speed Settings
/function speed_paths:set_1

Sets the movement bonus to Speed I.

/function speed_paths:set_2

Sets the movement bonus to Speed II.

/function speed_paths:set_3

Sets the movement bonus to Speed III.

/function speed_paths:set_4

Sets the movement bonus to Speed IV.

/function speed_paths:set_5

Sets the movement bonus to Speed V.

Admin
/function speed_paths:help

Displays every available command.

/function speed_paths:menu_speed_path

Opens the configuration menu.

/function speed_paths:give_book

Gives the Speed Paths configuration book.

/function speed_paths:enable

Enables the datapack and opens the configuration menu.

/function speed_paths:disable

Disables the Speed Paths effect.

/function speed_paths:unset

Resets the current speed level.

Installation

1. Download the datapack.
2. Place it inside your world's datapacks folder.
3. Run /reload or restart the world.
4. Run /function speed_paths:enable to configure your preferred speed level.

FAQ

Can I change the speed level?

Yes. You can choose any level between Speed I and Speed V using the built-in commands.

Does it work on servers?

Yes. Speed Paths works in both singleplayer and multiplayer worlds.

Does it require a resource pack?

No. The datapack works without any resource pack.

Can I disable it?

Yes. Simply use the disable command or reset the speed level whenever you want.
