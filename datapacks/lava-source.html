Lava Source

Renewable lava sources that generate infinitely, enabling automation and sustainable fuel systems.

Type Datapack / Mod
Version 1.21.9 - 26.2
Status Released

About

Lava Source is a datapack that makes lava a renewable resource by allowing lava sources to generate infinitely, similar to how water sources work in Minecraft.

By creating specific lava source configurations, players can build sustainable lava farms and produce an unlimited supply of lava over time, opening new possibilities for automation and large-scale survival projects.

Designed to feel natural within vanilla Minecraft, Lava Source expands existing fluid mechanics while keeping the gameplay balanced and familiar for both survival and technical players.

Features

Renewable Lava

Generate infinite lava sources over time, turning lava into a renewable resource for survival worlds.

Lava Automation

Create sustainable lava farms to power furnaces, fuel machines or support large-scale building projects.

Simple Setup

Easy to understand and use, with no commands or complicated configuration required.

Installation

1. Download the datapack.
2. Place it inside your world's datapacks folder.
3. Run /reload or restart the world.
4. Armorer villagers will automatically heal nearby Iron Golems.

FAQ

Does this replace vanilla mechanics?

No. The datapack only adds automatic healing behavior while keeping vanilla gameplay unchanged.

Does it work on servers?

Yes. It works in both singleplayer and multiplayer worlds.

Does it require a resource pack?

No. The datapack works without any resource pack.
